### Exercice 2 — Cibler des éléments

**Objectif** : écrire le sélecteur adapté à chaque consigne.
**Durée indicative** : 35 min



Le sélecteur **p** cible toutes les balises <p> du document, le sélecteur .**important** cible les éléments qui possèdent la class="important", le sélecteur **#entete** cible les éléments qui sont dans la balise <header> et qui portent l'attribut id="entete", le sélecteur **h1, h2** etc... cible les titres correspondants, le sélecteur **p.important** cible les paragraphes qui ont la class="important", le sélecteur **a.actif** cible les balises <a> qui ont la classe .actif, le sélecteur **footer p** cible les paragraphes qui se trouvent dans la balise <footer>, le sélecteur **#agenda li** cible les éléments de la liste <li> qui est contenu dans l'identifiant #agenda et enfin **.important.rappel** cible les éléments qui possèdent a la fois les classes .important et .rappel
