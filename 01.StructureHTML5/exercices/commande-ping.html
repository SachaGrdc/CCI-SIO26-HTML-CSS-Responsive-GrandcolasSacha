La commande ping

La commande ping est utilisée pour tester la connectivité réseau entre deux PC.

Syntaxe

Voici la syntaxe de la commande ping

Options courantes

  • ping -t
  • ping -a
  • ping -n
  • ping -l

Utilisation pas à pas

Attention ! Il faut bien suivre les étapes :

Tester le réseau local

  1. ping 192.168.1.1
  2. ping 192.168.1.2

Tester internet

  1. ping 8.8.8.8
  2. ping 8.8.4.4
