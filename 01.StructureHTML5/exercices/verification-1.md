### Vérification des acquis (15 min — sans IA)

```html
<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Serveurs et services</title>
</head>
<body>
  <h1>Les serveurs</h1>
  <p>Un serveur fournit des services à des clients.</p>
</body>
</html>
```



1) L'affichage ne pourrait pas fonctionner correctement car le système de décodage ne serait pas présent
2) Le contenu de 5 apparait dans le titre de l'onglet du navigateur ainsi que sur les moteurs de recherche, le 7 apparait dans la page web 
3) head contient les métadonnées, le titre de l'onglet ainsi que les liaisons avec les autres pages CSS et/ou JavaScript alors que body contient tout le contenu visible de la page (paragraphe, titre, etc..)
4) Le rôle du navigateur est d'afficher la page web. HTML sert à mettre en forme et à mettre le contenu, CSS sert à mettre en forme l'apparence et Javascript sert à animer la page.
