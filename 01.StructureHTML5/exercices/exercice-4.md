**### Exercice 4 — Expliquer la structure**

1)  !DOCTYPE html a pour but de définir la page comment étant de l'HTML5 


​	html a pour but de contenir tout le code HTML, c'est la racine du document

​	head a pour but de contenir toutes les métadonnées, le titre de l'onglet de la page ainsi que les liens avec les 	   	différentes pages tel que du CCS ou du JavaScript

​	meta a pour but de fournir toutes les métadonnées, elle se trouve dans la balise heat

​	title a pour but de définir un titre pour l'onglet de la page

​	body a pour but de contenir tout ce qui est visible dans la page

​	h1 a pour but de créer des titres, elle est contenu dans la balise body

​	p a pour but de créer des paragraphes, elle est contenu dans la balise body

2) Le titre dans de l'onglet sert à afficher le nom de la page dans les moteurs de recherche, il ne s'affiche pas dans la page, il se trouve dans une balise <title> elle même contenu dans <head> alors que le titre affiché dans la page est contenu dans la balise <h1> elle même contenu dans la balise <body> qui sert à afficher du contenu.
2) HTML sert à structurer la page et à mettre du contenu. CCS sert à mettre en forme l'apparence de la page et JavaScript sert à apporter de l'interactivité via des animations par exemple.
2) Tout d'abord le navigateur reçoit des octets, il les décode puis les convertit en DOM (arbre d'objets), dans le même temps il charge le CSS ainsi que le JavaScript, il les rajoute dans le DOM. Dans un second temps il calcul la taille et les positions de chaque "boite" à l'écran puis il transforme chaque boite en couche, ces couches sont ensuite converties en pixel, assemblées dans le bon ordre puis affiché.
