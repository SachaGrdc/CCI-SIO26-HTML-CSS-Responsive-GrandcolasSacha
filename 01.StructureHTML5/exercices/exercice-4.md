


# Exercice 4 — Documenter une commande



1) Tout d'abord j'ai mis une balise <h1> pour le titre principal puis pour chaque partie j'ai mis une balise <h2> pour les différentes parties et enfin j'ai utilisé la balise <h3> pour les sous-parties.
2) Le titre de l'onglet se trouve dans la balise <title> qui elle-même se trouve dans la balise <head>, ce titre n'est pas visible dans la page mais uniquement dans l'onglet du navigateur et sur le moteur de recherche tandis que le titre affiche dans la page se trouve dans une balise <h1>, <h2>, <h3>, <h4>, etc.... qui elle même se trouve dans la balise <body>.
3) L'HTML sert à structurer la page, le CSS sert à mettre en forme l'apparence et le JavaScript sert à mettre de l'interactivité
4)  Le navigateur lit d’abord le fichier HTML et le décode en UTF-8 grâce à <meta charset>, puis il transforme les balises en un arbre d’objets appelé DOM, en même temps il télécharge les ressources externes. Il assemble ensuite le DOM et les styles dans un arbre de rendu qui ne garde que les éléments visibles puis il calcule la taille et la position de chacun selon la largeur de la fenêtre et affiche le tout à l’écran.
