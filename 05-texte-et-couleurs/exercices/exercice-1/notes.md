### Exercice 1 — Mise en forme typographique

**Objectif** : appliquer des consignes de présentation à un document HTML existant.
**Durée indicative** : 25 min

#### Propriétés utilisées : 

font-size : définit la taille du texte 
 font-family : choisit la police
 color : couleur du texte
 background-color : couleur de fond
 text-align : alignement horizontal
 font-weight : épaisseur du texte
 font-style : inclinaison
 border-bottom : trait sous les titres h2

Formats de couleur

Hexadécimal (`#222222`, `#f5f5f5`, `#0b3d91`, `#555555`, `#f3f1a6`, `#7c3503`) : court et courant pour les couleurs fixes
 rgb(11, 61, 145) : le même bleu que le h1, utilisé pour les h2
 hsl(218, 86%, 31%) : le même bleu utilisé pour la bordure des h2
