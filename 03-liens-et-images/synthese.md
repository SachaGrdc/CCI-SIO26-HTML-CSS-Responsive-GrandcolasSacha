## Formalisation (20 min)

Synthèse : syntaxe de `a` et `img`, règles des chemins (`./`, `../`, dossier, racine), fragments, règles pour `alt`, liste de vérification d'un lien/image cassé.



#### Syntaxe

- Lien : 

  ```html
  <a href="destination.html">Destination</a>
  ```

   (on peut aussi mettre une image)

- Image : 

  ```html
  <img src="strasbourg.png" alt="image de Strasbourg">
  ```

   

#### Chemins

##### Chemin relatif : 

même dossier : fichier.html ou ./fichier.html

sous-dossier : dossier/fichier.html

dossier parent : ../fichier.html

https://test.com/fichier : URL absolue
